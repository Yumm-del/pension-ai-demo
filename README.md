# 工银智养仓 · 原型演示系统

> 第 17 届"工行杯"全国大学生金融科技创新大赛参赛作品
> **面向个人养老金业务的 AI 合规运营平台**（B 端客户经理工作台 + C 端 AI 养老顾问）

## 项目定位

用 AI 把"这个客户为什么不缴存"变成**可执行、可合规、可追踪**的运营动作：

- **分型**：规则初筛 + 大模型精判双引擎，识别休眠成因（不会投 / 不敢投 / 懒得投）
- **内容**：基于分型结果生成个性化合规激活话术，多渠道版本（短信 / 电话 / 面谈）
- **合规**：生成前受合规素材库约束、生成中敏感词实时检查、外发前人工审核与留痕
- **闭环**：分型 → 策略 → 触达 → 转化 → 留痕，全流程可审计

## 功能模块

| 模块 | 说明 |
|---|---|
| 📊 运营看板 | 客户总览、休眠成因分布、激活趋势 |
| 🔍 客户分型 | 双引擎分型输出（成因 + 置信度 + 人工复核提示） |
| 🤖 AI策略工场 | 生成候选激活策略，合规状态嵌入流程 |
| ⚡ 批量激活任务 | 批量触达与效率对比 |
| 📈 A/B效果对比 | 试点实验框架演示 |
| 🗂️ 客户库 | 200 位模拟脱敏客户画像 |
| 🔒 合规中心 | 三层防线 + 分级锁定 + 留痕审计 + 话术即时合规检查 |
| 🧮 税优计算器 | 客户沟通辅助工具 |

## 本地运行

```bash
pip install -r requirements.txt
streamlit run app.py
```

浏览器访问 http://localhost:8501

## 数据说明

**本演示系统全部使用程序生成的模拟脱敏数据，不代表任何真实银行客户信息或行内数据表现。**
演示数据使用固定随机种子，每次运行结果一致，便于演示复现。
